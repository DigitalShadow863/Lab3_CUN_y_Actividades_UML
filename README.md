## 🎯 Objetivo

Modelar los principales casos de uso y flujos de interacción de un sistema para apoyar la gestión de reservas y atención del Hotel Ginzha.

El laboratorio busca mantener trazabilidad entre los requisitos, actores, casos de uso, reglas de negocio, diagramas UML y prototipos de las principales pantallas del sistema.

---

## 📋 Alcance

El módulo seleccionado corresponde a la **Gestión de Reservas y Atención al Huésped**.

El alcance contempla:

* Consulta de disponibilidad de habitaciones.
* Registro de huéspedes.
* Registro de reservas.
* Confirmación de reservas.
* Validación de pagos.
* Check-in.
* Check-out.
* Consulta de reservas.
* Gestión básica de habitaciones.
